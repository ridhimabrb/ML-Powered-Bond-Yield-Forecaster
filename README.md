# ML-Powered Bond Yield Forecaster

## Overview

A quantitative finance and machine learning project that combines traditional fixed-income valuation techniques with predictive analytics.

The platform prices bonds using discounted cash flow (DCF) methodology and forecasts future Indian Government Security (G-Sec) yields using a Random Forest regression model trained on historical market data.


## Features

### Fixed Income Analytics

- Bond Pricing Calculator
- Cashflow Schedule Visualization
- Present Value Analysis
- Yield Sensitivity Curve
- Interest Rate Risk Visualization

### Machine Learning Forecasting

- Random Forest Regression
- 30-Day Yield Forecasting
- Time-Series Feature Engineering
- Rolling Average Indicators
- Volatility-Based Features

### Scenario Analysis

- Forecasted Yield Impact
- Future Bond Valuation
- Expected Price Change
- Yield Shock Analysis


## Dataset

Historical Indian 10-Year Government Security Yield Data

Columns Used:

- Price (Yield)
- Open
- High
- Low
- Change %

Period:

2016–2026

## Machine Learning Pipeline

Historical Yield Data
→ Feature Engineering
→ Random Forest Regression
→ Yield Forecast
→ Bond Repricing
→ Scenario Analysis
