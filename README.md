# ML-Powered Bond Yield Forecaster

## Overview

A quantitative finance and machine learning project that combines traditional fixed-income valuation techniques with predictive analytics.

The platform prices bonds using discounted cash flow (DCF) methodology and forecasts future Indian Government Security (G-Sec) yields using a Random Forest regression model trained on historical market data.

- Price (Yield)
- Open
- High
- Low
- Change %

Period:
